# Lumon 2.1.0

- Stop a running Auto Scan from the Dashboard, including scheduled scans
- Show stopping and stopped states while preserving scan history and available reports
- Keep incomplete scan findings out of the existing issue status
- Leave future schedules and Workspace settings unchanged

Repository preparation and report export finish before the scan stops. Completed
external actions are not undone. Scans started before this update cannot use the
new stop button

After upgrading, restart an idle Dashboard to load the new controls
